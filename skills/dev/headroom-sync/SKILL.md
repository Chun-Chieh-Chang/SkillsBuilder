# Headroom Sync Skill

Synchronize Headroom browser tabs to local cache for offline access and multi-device sync.

## Usage

Call this skill to fetch all tabs from Headroom API and save them to local cache.

## Output Format

- Total tabs synced
- Active/inactive tab counts
- Last sync timestamp
